# Outputs

Generated by `make reconcile` (and `make findings` for the report). Do not hand-edit.

| File | Generator | Contents |
|------|-----------|----------|
| `order_states.csv` | `reconcile` | `order_id, final_state, captured_inr, refunded_inr, mismatch` |
| `summary.json` | `reconcile` | headline totals: states, unique/duplicate/orphan/invalid events, mismatches, ₹ captured, refunded, fees, net settlement |
| `orphan_events.csv` | `reconcile` | events whose `order_id` is absent from `orders.csv` — reported, never processed |
| `mismatches.csv` | `reconcile` | captured ≠ billed orders with the paise delta |

These files contain your confidential figures. They are git-ignored by default —
attach them to the submission email / Drive link, do not push them to a public repo.
